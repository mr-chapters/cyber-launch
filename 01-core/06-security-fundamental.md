
### CVE and CVSS

**CVE** = Common Vulnerabilities and Exposures
- Unique ID for each vulnerability
- Format: CVE-YEAR-NUMBER
- Example: CVE-2021-44228 (Log4Shell)

**CVSS** = Common Vulnerability Scoring System
- Score from 0 to 10
- Higher = more severe

| Score | Severity |
|-------|----------|
| 0.0 | None |
| 0.1–3.9 | Low |
| 4.0–6.9 | Medium |
| 7.0–8.9 | High |
| 9.0–10.0 | Critical |

### Vulnerability lifecycle
1. Vulnerability discovered
2. Reported to vendor
3. Vendor creates patch
4. Patch released
5. Users update
6. Exploit may be public

### Why this matters
This is the language of security. You must speak it fluently.

## 9. Ethical Hacking and Laws (Detailed)

### What is ethical hacking?
Hacking with permission to find and fix weaknesses.

### Rules of engagement
1. Get written permission
2. Define scope (what is allowed)
3. Define timeline
4. Do not damage systems
5. Report findings
6. Keep it confidential

### Types of hackers

| Type | Permission | Intent | Example |
|------|------------|--------|---------|
| White hat | Yes | Good | Pen tester |
| Black hat | No | Bad | Criminal |
| Grey hat | No | Mixed | Finds bugs, asks reward |
| Script kiddie | No | Fun | Uses ready tools |
| Hacktivist | No | Cause | Anonymous |

### Laws you should know

| Law | Where | What it covers |
|-----|-------|----------------|
| CFAA | USA | Computer fraud |
| GDPR | EU | Data privacy |
| HIPAA | USA | Health data |
| PCI-DSS | Global | Card data |
| SOX | USA | Financial |
| Ghana CSA Act | Ghana | Cybersecurity |
| Cybercrime Act | Ghana | Cyber offenses |

### Penalties
- Fines (up to millions)
- Prison (up to 20+ years)
- Career ban
- Reputation damage

### Why this matters
Hacking without permission is a crime. Always get written consent. Keep records.

## 10. Security Policies and Awareness (Detailed)

### Common policies

| Policy | Purpose | Example rule |
|--------|---------|--------------|
| Acceptable Use | What users can do | No personal email |
| Password Policy | Password rules | 12+ chars, MFA |
| Incident Response | How to react | Report in 1 hour |
| Backup Policy | How to back up | Daily, offsite |
| Access Control | Who can access what | Least privilege |
| Data Classification | Label data | Public, internal, secret |
| Remote Work | Work from home | VPN required |
| BYOD | Personal devices | Must be encrypted |

### Security awareness topics
- Phishing recognition
- Password hygiene
- Physical security
- Social media safety
- Reporting incidents
- Clean desk policy
- Mobile security
- Travel security

### Awareness training methods
| Method | Pros | Cons |
|--------|------|------|
| Classroom | Interactive | Expensive |
| Online | Scalable | Boring |
| Simulated phishing | Real test | Can annoy |
| Posters | Cheap | Ignored |
| Gamification | Engaging | Time-consuming |

### Why this matters
Policies and awareness prevent more breaches than tools. A trained employee is your best firewall.
