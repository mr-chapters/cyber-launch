# 01 - Computer Fundamentals

Before you learn hacking, you must understand the machine you are hacking. This is the foundation of everything.

---

## What you will learn
- What a computer is
- Hardware basics

- Software vs hardware

---

## 1. What is a computer?
A computer is a machine that takes input, processes it, stores it, and gives output.

Four basic functions:
1. **Input** - keyboard, mouse, microphone
2. **Processing** - CPU does the thinking
3. **Storage** - hard drive, SSD, RAM
4. **Output** - monitor, speakers, printer

Everything in cybersecurity comes back to these four.

---

## 2. Hardware Basics

| Part | What it does |
|------|--------------|
| CPU | The brain. Processes instructions |
| RAM | Short-term memory. Fast but temporary |
| Storage (HDD/SSD) | Long-term memory. Keeps files |
| Motherboard | Connects everything together |
| GPU | Handles graphics and heavy math |
| PSU | Power supply |
| NIC | Network card. Connects to internet |

**Why this matters:** When you hack a machine, you are manipulating these parts through software.

---

## 3. Operating Systems
An OS is the software that manages hardware and runs programs.

Main ones:
- **Windows** - most common in companies
- **Linux** - most common on servers and in security
- **macOS** - Apple computers
- **Android / iOS** - phones

**What an OS does:**
- Manages files
- Runs programs
- Controls users and permissions
- Handles networking
- Manages memory

**Why this matters:** Most attacks target the OS. You must know how each one works.

---

## 4. Files and Folders
Everything on a computer is a file.

Common file types:
- `.txt` - text
- `.exe` - Windows program
- `.sh` - Linux script
- `.py` - Python script
- `.jpg` / `.png` - images
- `.log` - log files (important for security)
- `.conf` / `.ini` - config files

**File paths:**
- Windows: `C:\Users\YourName\Documents`
- Linux: `/home/yourname/documents`

**Why this matters:** Logs, configs, and scripts are files. Hackers read and modify files.

---

## 5. Software vs Hardware
- **Hardware** = physical parts you can touch
- **Software** = programs and instructions

Types of software:
- **System software** - OS, drivers
- **Application software** - browsers, games, tools
- **Malware** - software written to harm

**Why this matters:** Malware is just software. Understanding software helps you spot and stop it.

---

## 6. Virtual Machines (VMs)
A VM is a computer inside your computer.

**Why use a VM:**
- Safe place to practice hacking
- No risk to your real computer
- Easy to reset if you break it
- Run Linux inside Windows (or the reverse)

**Tools:**
- VirtualBox (free)
- VMware (free for personal use)

**Why this matters:** You will do most of your practice in a VM. Never hack on your real machine.
