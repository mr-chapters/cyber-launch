# Core Fundamentals

Before you choose a field, you must learn the core. This is the foundation every cybersecurity professional needs, no matter what path they pick.

Do not skip this. Do not rush this. Every field in cybersecurity builds on these 8 areas.

---

## Why the core matters
You cannot secure what you do not understand.
- You cannot defend a network if you do not know how networks work.
- You cannot find vulnerabilities if you cannot read code.
- You cannot respond to an attack if you do not know how systems operate.

The core is your base. Build it strong.

---

## The 8 Core Areas

### 1. Computer Fundamentals
Learn what a computer is, how it works, and how to use one properly.
- Hardware basics (CPU, RAM, storage)
- Operating systems (Windows, Linux, macOS)
- Files, folders, and file systems
- Software vs hardware
- Virtual machines

### 2. Linux Basics
Most security tools run on Linux. This is non-negotiable.
- What is Linux?
- Installing Ubuntu in a virtual machine
- The terminal
- Basic commands (ls, cd, pwd, cat, mkdir, rm)
- File permissions (chmod, chown)
- Users and groups
- Processes (ps, top, kill)
- Package management (apt)
- Text editors (nano, vim)

### 3. Networking
Attacks travel through networks. You must understand how data moves.
- What is a network?
- IP addresses and subnetting
- DNS
- DHCP
- TCP/IP and ports
- OSI model (7 layers)
- HTTP vs HTTPS
- Routers, switches, firewalls
- Basic tools (ping, traceroute, nslookup, netstat)

### 4. Windows Basics
Most companies run Windows. You need to know it.
- Windows OS overview
- Active Directory basics
- Command line (cmd) and PowerShell
- User accounts and permissions
- Windows security features
- Event Viewer and logs

### 5. Programming
You need to automate tasks and understand how software works.
- What is programming?
- Python basics (variables, data types)
- Loops (for, while)
- Conditionals (if, else)
- Functions
- Lists and dictionaries
- File handling
- Modules and libraries
- Bash scripting basics

### 6. Security Fundamentals
The concepts every security professional must know.
- What is cybersecurity?
- CIA Triad (Confidentiality, Integrity, Availability)
- Types of malware (virus, worm, trojan, ransomware)
- Phishing and social engineering
- Passwords and authentication
- Encryption basics
- Firewalls and antivirus
- Vulnerability vs exploit vs threat
- Ethical hacking and laws
- Security policies and awareness

### 7. Tools & Hands-On
Theory is not enough. You must practice.
- VirtualBox setup
- Kali Linux install
- Nmap basics
- Wireshark basics
- Burp Suite basics
- Metasploit basics
- Home lab setup
- Capture The Flag (CTF) basics

### 8. Soft Skills
Technical skills alone will not get you hired.
- Problem-solving
- Note-taking
- Research (Google, docs, man pages)
- Documentation (Markdown, GitHub)
- Communication
- Ethics and responsibility

---

## How to study the core
1. Go in order. Do not skip.
2. Do the practice tasks, not just reading.
3. Take notes in your own words.
4. Build something small after each area.
5. Review what you learned weekly.

Suggested pace: 3 to 6 months for the full core.
