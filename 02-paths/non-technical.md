## 1. What are Non-Technical Roles?

Non-technical roles in cybersecurity do not require you to hack, code, or configure systems. Instead, you use other skills: communication, writing, law, sales, training, or management.

**Why these roles matter:**

- Someone must train employees
- Someone must handle legal issues
- Someone must sell security products
- Someone must write documentation
- Someone must lead the team
- Someone must hire talent

**The reality:**

- Easier to enter than technical roles
- Leverages existing skills
- Still requires security knowledge
- Good salaries
- Less competition for some roles

**Technical vs Non-Technical:**

| Aspect | Technical | Non-Technical |
|--------|-----------|---------------|
| Coding | Required | Not needed |
| Daily | Systems, tools | People, documents |
| Entry | Harder | Easier |
| Skills | Technical | Communication |
| Salary | Higher | Good |

## 2. Every Role Explained in Detail

### Security Awareness Trainer

**What you do:**

You teach employees how to recognize and avoid security threats.

**Daily tasks:**

- Create training content
- Run phishing simulations
- Track completion rates
- Report metrics
- Improve the program
- Present to teams
- Handle questions

**Example day:**

```
09:00 - Check phishing simulation results
09:30 - Design new training module
11:00 - Present to marketing team
12:00 - Lunch
13:00 - Update training platform
14:30 - Analyze metrics
16:00 - Plan next campaign
17:00 - Document
```

**Example task — phishing simulation:**

```
Task: Run phishing simulation

Step 1: Design fake email
Step 2: Get approval
Step 3: Send to 500 employees
Step 4: Track who clicked
Step 5: Track who reported
Step 6: Send follow-up training
Step 7: Report results
Step 8: Improve program
```

**Skills you need:**

- Communication
- Presentation
- Training design
- Psychology basics
- Data analysis
- Writing

**Tools you use:**

- KnowBe4
- Proofpoint
- Cofense
- LMS platforms
- Survey tools

**Challenges:**

- Engagement
- Repetition
- Measuring success
- Limited time
- Resistance

**How to succeed:**

- Make it engaging
- Use real examples
- Track metrics
- Get leadership support
- Iterate constantly
