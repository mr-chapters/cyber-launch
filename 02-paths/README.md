# Paths

You finished the core. Now choose your path. Each path is a deep-dive into one field of cybersecurity. Read each one, see what fits you, then commit.

---

## How to choose
Do not pick based on salary alone. Pick based on what you enjoy doing daily.

Ask yourself:
1. Do I like defending or attacking?
2. Do I like building or breaking?
3. Do I like people or systems?
4. Do I like fast action or deep analysis?
5. Do I like policy or technology?

Your answers point to your path.

---

## The 8 Paths

### 1. Blue Team (Defense)
You protect the organization. You monitor, detect, and respond to threats.

**Roles:** SOC Analyst, Incident Responder, Threat Hunter, Forensics Analyst, Malware Analyst

**Daily work:**
- Watch dashboards and alerts
- Investigate suspicious activity
- Write incident reports
- Improve detection rules
- Hunt for hidden threats

**Skills you need:**
- SIEM (Splunk, ELK)
- Log analysis
- Incident response
- Threat intelligence
- MITRE ATT&CK

**Tools:**
- Splunk, ELK, Wazuh
- Wireshark, Zeek
- Volatility, Autopsy
- VirusTotal, Any.run

**Personality fit:** Patient, analytical, calm under pressure

**Entry difficulty:** Easy (most common entry point)

→ Read more: `blue-team.md`

---

### 2. Red Team (Offense)
You are paid to think like an attacker.

**Roles:** Penetration Tester, Ethical Hacker, Red Team Operator, Bug Bounty Hunter, Exploit Developer

**Daily work:**
- Scan targets
- Find vulnerabilities
- Exploit them safely
- Write reports
- Advise fixes

**Skills you need:**
- Nmap, Burp Suite, Metasploit
- Web exploitation
- Network exploitation
- Scripting (Python, Bash)
- Report writing

**Tools:**
- Kali Linux
- Nmap, Burp Suite
- Metasploit, Empire
- SQLmap, Hydra
- Cobalt Strike (paid)

**Personality fit:** Curious, creative, persistent, ethical

**Entry difficulty:** Medium (needs strong fundamentals)

→ Read more: `red-team.md`

---

### 3. Cloud Security
You secure the platforms everything runs on.

**Roles:** Cloud Security Engineer, Cloud Security Architect, DevSecOps Engineer

**Daily work:**
- Review cloud configs
- Manage IAM policies
- Secure containers
- Automate security
- Respond to cloud incidents

**Skills you need:**
- AWS, Azure, or GCP
- IAM
- Containers (Docker, Kubernetes)
- Infrastructure as Code (Terraform)
- CI/CD pipelines

**Tools:**
- AWS Security Hub
- Azure Defender
- Terraform
- Docker, Kubernetes
- Checkov, Trivy

**Personality fit:** Builder, systematic, automation-minded

**Entry difficulty:** Medium (needs cloud knowledge)

→ Read more: `cloud-security.md`

---

### 4. GRC (Governance, Risk & Compliance)
You bridge security and business.

**Roles:** GRC Analyst, Security Auditor, Compliance Officer, Risk Analyst, Privacy Officer

**Daily work:**
- Review policies
- Assess risks
- Prepare audits
- Ensure compliance
- Write reports

**Skills you need:**
- Risk assessment
- Frameworks (ISO 27001, NIST)
- Regulations (GDPR, HIPAA)
- Auditing
- Documentation

**Tools:**
- Excel, GRC platforms
- Risk registers
- Policy templates
- Audit checklists

**Personality fit:** Organized, detail-oriented, business-minded

**Entry difficulty:** Easy (non-technical friendly)

→ Read more: `grc.md`

---

### 5. IAM (Identity & Access Management)
You control who can access what.

**Roles:** IAM Engineer, Identity Analyst, PAM Specialist, Authentication Engineer

**Daily work:**
- Manage user accounts
- Configure SSO
- Enforce MFA
- Review access
- Automate provisioning

**Skills you need:**
- Active Directory
- LDAP, SAML, OAuth
- MFA, SSO
- Privileged access
- Identity lifecycle

**Tools:**
- Okta, Azure AD
- SailPoint, Saviynt
- CyberArk, BeyondTrust
- Keycloak

**Personality fit:** Methodical, precise, security-focused

**Entry difficulty:** Medium (underrated entry point)

→ Read more: `iam.md`

---

### 6. AI Security
You secure AI and machine learning systems.

**Roles:** AI Security Analyst, ML Security Engineer, AI Red Teamer

**Daily work:**
- Test LLMs for weaknesses
- Detect prompt injection
- Secure AI pipelines
- Monitor AI behavior
- Research new threats

**Skills you need:**
- Python, ML basics
- LLM architecture
- OWASP Top 10 for LLM
- MITRE ATLAS
- Adversarial ML

**Tools:**
- Garak
- PyRIT
- Promptfoo
- LangChain
- Custom scripts

**Personality fit:** Cutting-edge, research-minded, adaptable

**Entry difficulty:** Hard (new field, few guides)

→ Read more: `ai-security.md`

---

### 7. Security Engineering
You design and build secure systems.

**Roles:** Security Engineer, Security Architect, Security Consultant, Solutions Architect

**Daily work:**
- Design security systems
- Deploy tools
- Automate security
- Review architecture
- Advise teams

**Skills you need:**
- Networking
- Linux, Windows
- Scripting
- Cloud
- Architecture

**Tools:**
- Firewalls, IDS/IPS
- SIEM
- Automation tools
- Cloud platforms

**Personality fit:** Builder, strategic, systems-thinker

**Entry difficulty:** Medium-Hard (needs experience)

→ Read more: `engineering.md`

---

### 8. Non-Technical & Hybrid
You do not need to code to work in cybersecurity.

**Roles:** Security Awareness Trainer, Cybersecurity Lawyer, Sales Engineer, Technical Writer, Recruiter, CISO

**Daily work:**
- Train employees
- Handle legal issues
- Sell security products
- Write documentation
- Hire talent
- Lead the program

**Skills you need:**
- Communication
- Business acumen
- Writing
- People skills
- Domain knowledge

**Tools:**
- PowerPoint
- LMS platforms
- CRM
- Documentation tools

**Personality fit:** People-oriented, communicative, business-minded

**Entry difficulty:** Easy (leverages existing skills)

→ Read more: `non-technical.md`

## Can you switch paths?
Yes. Many people start in Blue Team and move to Red Team. Others start in GRC and move to Cloud. Your core skills transfer.

**Common moves:**
- SOC → Threat Hunter → Red Team
- Help Desk → IAM → Cloud
- Developer → DevSecOps → Cloud
- Auditor → GRC → CISO
