# Cybersecurity Fields

Before you start learning, you need to know what exists. Cybersecurity is not one job — it is many different careers. Read through this list, see what interests you, then go learn the core (01-core) before choosing a path.

---

##  Defensive Security (Blue Team)
You protect the organization. You monitor, detect, and respond to threats.

| Role | What you do |
|------|-------------|
| SOC Analyst | Monitor alerts and investigate suspicious activity |
| Incident Responder | Jump in during active breaches to contain damage |
| Threat Hunter | Proactively search for hidden threats |
| Digital Forensics Analyst | Recover and analyze evidence from devices |
| Malware Analyst | Study malicious software to understand how it works |
| Security Operations Manager | Lead the defense team |

**You might like this if:** You enjoy fast-paced problem-solving and catching things before they get worse.

---

##  Offensive Security (Red Team)
You are paid to think like an attacker and find weaknesses before real hackers do.

| Role | What you do |
|------|-------------|
| Penetration Tester | Run authorized simulated attacks on systems |
| Ethical Hacker | Same as above, older term |
| Red Team Operator | Simulate full-scale adversary campaigns |
| Bug Bounty Hunter | Find bugs independently for rewards |
| Exploit Developer | Write code that takes advantage of vulnerabilities |
| Vulnerability Researcher | Discover new classes of bugs in software |

**You might like this if:** You enjoy breaking things legally and thinking like a criminal.

---

##  Cloud & Infrastructure Security
You secure the platforms and networks everything runs on.

| Role | What you do |
|------|-------------|
| Cloud Security Engineer | Protect AWS, Azure, or GCP environments |
| Cloud Security Architect | Design secure cloud systems |
| Network Security Engineer | Focus on firewalls, VPNs, and traffic |
| DevSecOps Engineer | Embed security into software development |
| AppSec Engineer | Secure applications before they ship |
| Infrastructure Security Analyst | Monitor and protect servers and systems |

**You might like this if:** You enjoy building and securing systems at scale.

---

##  Governance, Risk & Compliance (GRC)
You bridge the gap between technical security and business/legal requirements.

| Role | What you do |
|------|-------------|
| GRC Analyst | Ensure the organization meets regulations |
| Security Auditor | Evaluate if controls meet standards |
| Compliance Officer | Focus on legal and regulatory alignment |
| Risk Analyst | Identify and measure security risks |
| Privacy Officer | Protect personal data and privacy |
| Policy Writer | Write security policies and procedures |

**You might like this if:** You enjoy policy, law, structure, and documentation.

---

##  Identity & Access Management (IAM)
You control who can access what.

| Role | What you do |
|------|-------------|
| IAM Engineer | Build and manage identity systems |
| Identity Analyst | Monitor and analyze access patterns |
| PAM Specialist | Secure privileged accounts |
| Authentication Engineer | Build login and authentication systems |

**You might like this if:** You enjoy order, access control, and preventing unauthorized entry.

---

##  Emerging & Specialized
Newer fields that are growing fast.

| Role | What you do |
|------|-------------|
| AI Security Analyst | Secure AI and LLM systems |
| IoT Security Specialist | Protect connected devices |
| OT / ICS Security Engineer | Protect industrial control systems |
| Blockchain Security Analyst | Secure blockchain applications |
| Cryptographer | Design and break encryption |
| Quantum Security Researcher | Prepare for quantum computing threats |

**You might like this if:** You enjoy new technology and being ahead of the curve.

---

## Security Engineering & Architecture
You design and build secure systems.

| Role | What you do |
|------|-------------|
| Security Engineer | Build and maintain security tools |
| Security Architect | Design the overall security structure |
| Security Consultant | Advise organizations on security |
| Solutions Architect | Design security solutions for clients |
| Security Analyst (Generalist) | Handle a bit of everything |

**You might like this if:** You enjoy designing and building things.

---

## Non-Technical & Hybrid Roles
You do not need to code to work in cybersecurity.

| Role | What you do |
|------|-------------|
| Security Awareness Trainer | Teach employees about security |
| Cybersecurity Lawyer | Handle legal issues in cyber |
| Security Sales Engineer | Sell security products |
| Technical Writer (Security) | Write documentation and guides |
| Cybersecurity Recruiter | Hire security professionals |
| CISO | Lead the entire security program |

**You might like this if:** You enjoy people, communication, and business.

---

##  Which One Fits You?

| If you like... | Consider... |
|----------------|-------------|
| Fast-paced alert response | SOC Analyst |
| Breaking things legally | Penetration Tester |
| Building and securing systems | Security Engineer |
| Policy, law, and structure | GRC / Compliance |
| Cloud platforms (AWS/Azure) | Cloud Security Engineer |
| AI and new tech | AI Security Analyst |
| Teaching and people | Security Awareness Trainer |
| Management and strategy | CISO / Security Manager |

---

## What now?
Do not pick a field yet. First, go to **01-core** and learn the fundamentals. After the core, come back here and choose your path in **02-paths**.

> ⚠️ Ethical Use Only
> Only hack systems you own or have written permission to test.
> Never use these skills to break the law.
